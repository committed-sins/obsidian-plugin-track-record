# Track Record 0.1.9

- History reads the current and previous Timer and Status destination folders. Use **Additional records folder** for records that live elsewhere.
- Set **Notes folder** to limit subject selection, link suggestions and subject ID checks to a folder and its subfolders. A blank setting allows notes anywhere in the vault.
- On upgrade, include previously moved records before starting a new timer. Track Record reports a previously observed timer whose file is still present outside the search folders and prevents reducing the search scope while it would hide an open timer.
