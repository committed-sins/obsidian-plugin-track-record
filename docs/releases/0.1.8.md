# Track Record 0.1.8

- New timer and status filenames use compact UTC times. The `{timestamp}` token uses `YYYY-MM-DDThhmmssZ`, as in `Timer - 2026-11-24T174539Z.a1b2c3.md`. Existing records work with their current filenames.
- The local date formatter validates the output from Obsidian's Moment API. This resolves the source review warnings reproduced when Moment type declarations are unavailable.
