# Track Record 0.1.6

First public release, approved after Test-vault evaluation on 2026-11-21.

- Track work intervals and status events as ordinary linked Markdown notes.
- Start and stop timers across synchronized devices using an optional user name. Unassigned users only close unassigned timers.
- Review timers that remained open after Obsidian closed. Continue, end at the recorded closing/last-active time, or choose another end time. No automatic end is written.
- Use separate Timer and Status views, native date/time pickers, multiple subject selections and editable status suggestions.
- Save Markdown notes under a configurable heading, with link insertion and preview.
- Configure record folders, tags, filename formats and nested or flat properties. New timestamps use UTC; inputs and history show local time.

## Compatibility and limits

Requires Obsidian 1.11.4 or later. Mobile APIs are supported by the bundle; live Android acceptance remains pending. App termination callbacks are best effort; crash/mobile fallback uses a 30-second local heartbeat. Plugin reloads/unloads are labelled last-active rather than app-closing events. Sleeping is not automatically subtracted. Only synchronized notes can be acted on, and concurrent cross-device writes are ordinary vault-note conflicts.

Older preview records remain readable without automatic rewriting. There is no account, server, analytics or automatic source-status editing. Current-user and interruption reminders are stored locally; tracking records remain in the vault.

Assets: main.js, manifest.json, styles.css. License notices and SHA256SUMS are included alongside them.
