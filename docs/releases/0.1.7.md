# Track Record 0.1.7

This update separates the timer and status histories into independently dockable views. Open either from the command palette or its ribbon icon. An existing Track Record pane becomes the Timer view.

- Choose how local dates and times appear in history, running timer cards, and interruption reminders. The default is `YYYY-MM-DD HH:mm:ss`, and the setting previews your chosen Moment pattern. Records still store UTC timestamps.
- Add or remove subjects in the record dialog using compact chips beside the note controls. The status field appears before the effective time. Link insertion and Markdown preview sit with the notes field.
- See date and filename examples alongside the corresponding settings.
- Find Track Record settings through Obsidian's settings search in Obsidian 1.13 and later.

The update reads existing records and supports existing filename patterns and property mappings without migration.

GitHub Actions builds and attests the three release assets. Use `gh attestation verify <file> --repo committed-sins/obsidian-plugin-track-record` to verify their provenance.
